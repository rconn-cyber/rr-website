Syncs all members and events between Wild Apricot and Supabase in both directions. When the same record has been updated in both places, the most recently modified version wins.

Direction WA ↔ Supabase (bidirectional)

Syncing members and events… this may take 15–30 seconds.
HOW IT WORKS

Wild Apricot is the primary source for member status, level, and billing data. Supabase is the primary source for website-specific fields like rank, admin_type, and photo_url. Events created in Wild Apricot sync into Supabase automatically. Events created directly in Supabase are pushed to Wild Apricot as new events. The scheduled sync runs every hour via Netlify. Check Netlify function logs for sync history.
